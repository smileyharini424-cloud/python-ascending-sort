# Sort Numbers in Ascending Order

## Explanation

This program arranges a list of numbers from the smallest value to the largest value.

## Problem Statement

Write a Python program to sort a list of numbers in ascending order.

## Features

* Accepts multiple numbers
* Sorts the values
* Displays the sorted list

## How It Works

The `sorted()` function creates a new list containing the numbers in ascending order.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `map()`
* `sorted()`

## Program Flow

1. Read numbers
2. Convert them into integers
3. Sort the numbers
4. Display the result

## Sample Input

```text
45 12 8 30 20
```

## Sample Output

```text
Ascending order: [8, 12, 20, 30, 45]
```

## Time Complexity

O(n log n)

## Space Complexity

O(n)
